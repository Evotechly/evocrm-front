# Shoogle component registry

Status: research-only for Wave 0. No Shoogle component was adopted in the foundation.

The project brief requires license, React compatibility, dependency conflict, accessibility, maintenance, and existing-component comparison before adoption. The current shell uses small local primitives (`Button`, `Badge`, `Panel`, `DataTable`, `CommandPalette`) to keep dependency surface low. Each future candidate must be recorded here with source URL, license, version, decision, and attribution before installation.
